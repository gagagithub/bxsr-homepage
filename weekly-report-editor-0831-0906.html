⛔ 最该先改的一条

「存了30万的朋友注意，上面有新动作了」——本周唯一的 12.8 万播放爆款， 靠的正是「上面有新动作」这种暗示国家政策变动的钩子。 流量最好的一条同时是风险最高的一条，这个组合最危险： 它会诱导团队继续复制这个句式。建议这条句式立刻停用，别等新规。

✅ 可以放心复制的句式

「存款 X 万 → 每年领 Y / 每月领 Z」这一类纯数字场景句， 本周在两个阵地都跑出了量（公众号 5,186 / 3,660 / 2,950，视频号 15,500 / 7,253 / 6,900）， 而且不含承诺收益词、不含绝对化用语、不暗示政策。 这是既能跑量又能过新规的句式，应该定为主力模板。
